# Exemplos de uso

1. Inicie a interface com `OPENAI_API_KEY` definida no ambiente e execute `python app.py`.
2. No campo de mensagem, envie: `Explique soberania digital em linguagem simples.`
3. Compare respostas alterando `OPENAI_MODEL`, respeitando disponibilidade e custos do provedor.

Este exemplo usa a API OpenAI externa. Não inclua credenciais, dados pessoais ou conteúdo confidencial na conversa.
